# Versioning

Use MAJOR.MINOR.PATCH:

- MAJOR: incompatible configuration, entity or behavior changes.
- MINOR: backward-compatible features.
- PATCH: backward-compatible fixes and maintenance.

The requested first maintained release is `0.1.0`. Keep `custom_components/lu_alert/manifest.json`, CHANGELOG and annotated Git tag aligned. Tags do not use a leading `v`.
