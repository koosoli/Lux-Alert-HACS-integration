# Changelog

Notable changes are documented here. Dates use ISO format (YYYY-MM-DD).

## [0.1.0] - 2026-11-06

### Added
- Initial maintained release baseline for the Luxembourg LU-Alert Home Assistant integration.
- CAP dataset retrieval, parsing, filtering and Home Assistant entity platforms.
- Coordinator cache, expiry scheduling, retry backoff and last-known-data behavior.
- Lovelace alert card and bundled Leaflet assets.
- Repository development, testing, security and release standards.
- GitHub Actions for tests, Home Assistant validation and HACS validation.

### Release notes
- Publish only after all CI checks and manual smoke tests pass.
- Confirm supported functionality and known limitations against the release candidate.
