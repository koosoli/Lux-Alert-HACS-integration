# Code of Conduct

We aim to provide a welcoming, respectful and harassment-free environment.

Expected behavior: be respectful and constructive, critique code rather than people, accept differing opinions, respect privacy and do not publish personal information.

Harassment, discrimination, threats, personal attacks, doxxing and deliberate intimidation are unacceptable. Maintainers may remove violating contributions or restrict participation.

Report conduct concerns privately to the repository owner through the contact method on their GitHub profile. Do not use public issues for sensitive reports.
